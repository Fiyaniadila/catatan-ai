1
Inisialisasi weight secara random

Model belum tau apa-apa. Nilai weight (w) diisi angka acak kecil sebagai titik awal. Untuk project kamu, setiap fitur input punya weight sendiri.

w = random()       # misal: 0.23
b = random()       # bias juga random

# Untuk banyak fitur:
W = [w1, w2, w3, ..., wn]  # satu w per fitur
2
Forward pass — hitung prediksi

Input dimasukkan ke model untuk menghasilkan prediksi. Model mengalikan setiap fitur dengan weight-nya masing-masing.

# 1 fitur:
y_pred = w · x

# Banyak fitur (project kamu):
y_pred = w1·x1 + w2·x2 + ... + wn·xn + b
= W · X + b
3
Hitung Loss — seberapa salah?

Bandingkan prediksi dengan nilai asli. Tujuan training = membuat Loss sekecil mungkin.

# MSE (Mean Squared Error):
L = (y_pred - y_act)²

# Huber Loss (rekomendasi project kamu):
L = { 0.5·(y_pred - y_act)²   jika |error| ≤ δ
{ δ·|error| - 0.5·δ²     jika |error| > δ
4
Hitung Gradient — arah turun

Cari turunan Loss terhadap W menggunakan Chain Rule. Gradient menunjukkan ke arah mana weight harus digeser.

# Chain Rule:
dL/dw = dL/dy_pred · dy_pred/dw

dL/dy_pred = 2(y_pred - y_act)
dy_pred/dw = x     # karena y_pred = w·x

∴ dL/dw = 2(w·x - y_act) · x ✓

# Di LSTM: proses ini disebut BPTT
# t=1←t=2←t=3←t=4←t=5 (gradient mundur)
5
Update weight — inti gradient descent!

Geser weight ke arah yang mengurangi Loss. Inilah inti dari gradient descent — weight diupdate menggunakan gradient yang sudah dihitung.

w_baru = w_lama - α · dL/dw

# α = learning rate
# Terlalu besar → lompat-lompat
# Terlalu kecil → sangat lambat

# Untuk banyak fitur:
w1 = w1 - α · dL/dw1
w2 = w2 - α · dL/dw2
... # semua diupdate sekaligus
6
Ulangi sampai konvergen

Proses step 2–5 diulang berkali-kali sampai Loss tidak bisa turun lagi. Gunakan EarlyStopping agar otomatis berhenti.

Epoch 1: Loss = 4.52 ↓
Epoch 10: Loss = 1.23 ↓
Epoch 50: Loss = 0.18 ↓
Epoch 100: Loss = 0.09 ↓
Epoch 200: Loss = 0.08 ← konvergen ✓

Apa itu activation function?

Tanpa activation function, neural network hanya bisa memodelkan hubungan linier — berapapun layer yang ditambahkan, hasilnya tetap persamaan garis lurus. Activation function menambahkan non-linearitas sehingga model bisa belajar pola yang kompleks.

🔌 Analogi Saklar

Bayangkan neuron sebagai saklar listrik. Tanpa activation function, setiap neuron selalu meneruskan sinyal apa adanya. Dengan activation function, neuron bisa memutuskan: "apakah sinyal ini cukup penting untuk diteruskan ke layer berikutnya?"

Posisi di neural network
Input → [Linear: W·X + b] → [Activation] → Output

# Tanpa activation (cuma linier):
Layer1: y = W1·x + b1
Layer2: y = W2·(W1·x+b1) + b2 = masih linier!

# Dengan activation:
Layer1: y = ReLU(W1·x + b1)
Layer2: y = ReLU(W2·y + b2) → non-linier! ✓
ReLU Paling populer
f(x) = max(0, x)

Negatif jadi 0, positif diteruskan. Cepat dan efisien. Masalah: dying ReLU jika neuron selalu dapat input negatif.

✓ Cocok untuk: hidden layer umum, CNN
Sigmoid Klasik
f(x) = 1 / (1 + e⁻ˣ)

Output selalu antara 0–1. Bagus untuk probabilitas. Masalah: vanishing gradient di ujung kurva (saturasi).

✓ Cocok untuk: output layer klasifikasi biner, gate LSTM
Tanh Di LSTM!
f(x) = (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)

Output antara −1 hingga +1, terpusat di nol. Lebih baik dari Sigmoid untuk hidden layer. Dipakai di gate LSTM.

✓ Cocok untuk: cell state LSTM, hidden layer RNN
Leaky ReLU
f(x) = x  jika x>0
f(x) = 0.01x jika x≤0

Perbaikan dari ReLU — negatif tidak langsung jadi 0, tapi dikali 0.01. Mencegah dying ReLU.

✓ Cocok untuk: pengganti ReLU jika banyak neuron mati
Softmax Klasifikasi
f(xᵢ) = eˣⁱ / Σeˣʲ
0.1
0.7
0.05
0.15

Mengubah output menjadi distribusi probabilitas — semua nilai positif dan jumlahnya = 1.0.

✓ Cocok untuk: output layer klasifikasi multi-kelas
Linear Tanpa aktivasi
f(x) = x

Tidak ada transformasi non-linier. Dipakai di output layer untuk prediksi nilai kontinu (regresi).

✓ Cocok untuk: output layer regresi (project kamu!)
Activation function di LSTM — project kamu

LSTM punya 4 gate, masing-masing pakai activation function yang berbeda sesuai fungsinya:

# 4 gate di LSTM:
Forget gate : f = sigmoid(Wf·[h,x] + bf) # 0-1: lupakan?
Input gate : i = sigmoid(Wi·[h,x] + bi) # 0-1: simpan?
Cell update : g = tanh(Wg·[h,x] + bg) # -1,1: nilai baru
Output gate : o = sigmoid(Wo·[h,x] + bo) # 0-1: keluarkan?

c_t = f * c_prev + i * g
h_t = o * tanh(c_t) # output akhir tiap timestep
SIGMOID di gate
Output 0–1 = cocok untuk "seberapa banyak yang dilewatkan" (0=blokir, 1=lewatkan semua)
TANH di cell/output
Output −1 hingga +1 = cocok untuk nilai yang bisa naik atau turun (beban trafo fluktuatif)

Backpropagation = Analisis Kesalahan Mundur
🍳 Analogi: Nasi Goreng Keasinan

Kamu masak nasi goreng, hasilnya keasinan (= Loss besar). Pertanyaannya bukan "berapa asin garamnya" — tapi: "kalau garam dikurangi 1 sendok, keasinan berkurang berapa?"

# Setiap bahan = satu weight
# Gradient = seberapa besar kontribusi tiap bahan ke keasinan

dL/dw_garam = +8.2 ← garam pengaruh besar ke keasinan
dL/dw_kecap = +3.1 ← kecap pengaruh sedang
dL/dw_saos = +0.4 ← saos pengaruh kecil
Backprop vs Gradient Descent — bedanya apa?
BACKPROPAGATION
ANALISIS kesalahan
"Ini salahnya dimana dan seberapa besar pengaruh tiap weight ke Loss"
loss.backward()
GRADIENT DESCENT
UPDATE weight
"Oke, sekarang perbaiki semua weight berdasarkan hasil analisis tadi"
optimizer.step()
Backprop tanpa gradient descent = tahu masalahnya tapi tidak diperbaiki
Gradient descent tanpa backprop = mau perbaiki tapi tidak tahu yang mana
Keduanya bersama = AI bisa belajar! ✓

1
Forward pass — prediksi dulu

Model membaca input dan menghasilkan prediksi. Semua nilai di setiap layer disimpan karena dibutuhkan saat mundur nanti.

# Contoh project kamu:
input = [suhu=32, jam=8, beban_lalu=150]
y_pred = model(input) # → 160 MW
y_actual = 175 # kenyataannya
2
Hitung Loss — seberapa meleset?

Bandingkan prediksi dengan kenyataan. Loss yang besar = prediksi jauh meleset.

Loss = (y_pred - y_actual)²
= (160 - 175)²
= (-15)²
= 225 ← terlalu besar! perlu diperbaiki
3
Backprop — mundur, hitung gradient tiap weight

Inilah inti backpropagation. Bukan hitung "loss tiap weight" — tapi hitung "kalau weight ini diubah sedikit, loss naik atau turun seberapa?"

# Rumus gradient (dari Chain Rule):
dL/dw = 2(y_pred - y_actual) · x

# Hasil untuk tiap weight:
dL/dw_suhu = 2(-15) · 32 = -960 ← w_suhu terlalu kecil
dL/dw_jam = 2(-15) · 8 = -240 ← w_jam terlalu kecil
dL/dw_beban_lalu = 2(-15) · 150 = -4500 ← paling berpengaruh!
4
Arti nilai gradient

Nilai gradient memberi tahu dua hal sekaligus: arah (perlu naik atau turun) dan besarnya perubahan yang dibutuhkan.

dL/dw = negatif (-) → weight terlalu kecil → perlu dibesarkan
dL/dw = positif (+) → weight terlalu besar → perlu dikecilkan
dL/dw = nol (0) → weight sudah pas → tidak perlu diubah
|dL/dw| besar → kontribusi weight ke error besar → perubahan lebih besar
5
Update weight — gradient descent!

Pakai gradient hasil backprop untuk update semua weight sekaligus.

# α = 0.001 (learning rate)

w_suhu_baru = w_suhu - 0.001 · (-960)
= w_suhu + 0.96 ← naik ✓

w_jam_baru = w_jam - 0.001 · (-240)
= w_jam + 0.24 ← naik ✓

w_beban_lalu_baru = w_beban_lalu - 0.001 · (-4500)
= w_beban_lalu + 4.5 ← naik paling banyak ✓
✓ Prediksi berikutnya akan lebih mendekati 175 MW!
Di LSTM: namanya BPTT

Di LSTM ada dimensi tambahan yaitu waktu — gradient harus mundur melewati setiap timestep:

# Forward: kiri ke kanan
t=1 → t=2 → t=3 → t=4 → t=5 → output

# Backward (BPTT): kanan ke kiri
t=1 ← t=2 ← t=3 ← t=4 ← t=5 ← Loss

# Gradient mengalir mundur melewati setiap timestep
# Makanya disebut Backpropagation Through TIME
BACKPROP BIASA
Mundur melewati layer (vertikal)
Layer3 ← Layer2 ← Layer1
BPTT (LSTM)
Mundur melewati layer DAN waktu
t5 ← t4 ← t3 ← t2 ← t1
Kode lengkap 1 iterasi training
# 1. Forward pass
y_pred = model(X)

# 2. Hitung loss
loss = criterion(y_pred, y_actual)

# 3. Reset gradient lama (WAJIB sebelum backprop)
optimizer.zero_grad()

# 4. BACKPROPAGATION — hitung gradient semua weight
loss.backward()

# 5. Gradient clipping (cegah exploding gradient)
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# 6. GRADIENT DESCENT — update semua weight
optimizer.step()
⚠️ zero_grad() wajib dipanggil sebelum backward() — kalau tidak, gradient lama akan terakumulasi dan merusak training!
Ringkasan — 3 konsep yang sering tertukar
Backprop
Hitung seberapa besar pengaruh tiap weight ke Loss — pakai Chain Rule mundur dari output ke input
Gradient Descent
Update weight menggunakan gradient hasil backprop — geser weight ke arah yang kurangi Loss
BPTT
Backprop versi LSTM — mundur melewati layer dan timestep sekaligus

Analogi 5
Activation Function = Kepribadian Neuron

Setiap jenis activation function punya "kepribadian" yang berbeda dalam merespons sinyal masuk:

😤
ReLU — "Kalau tidak positif, saya diam"
Keras dan tegas. Hanya meneruskan sinyal positif, langsung buang yang negatif. Efisien tapi bisa terlalu keras.
😌
Sigmoid — "Saya selalu kasih pendapat, tapi tidak pernah ekstrem"
Selalu output antara 0–1. Tidak pernah bilang "ya 100%" atau "tidak 0%" secara ekstrem — selalu ada di tengah.
⚖️
Tanh — "Saya bisa positif atau negatif, tapi tetap seimbang"
Terpusat di nol. Bisa ekspresikan nilai positif DAN negatif. Cocok untuk data yang bisa naik-turun seperti beban trafo.
🤝
Leaky ReLU — "Saya keras, tapi tidak kejam"
Seperti ReLU tapi tidak langsung bunuh sinyal negatif — dikecilkan sedikit saja. Lebih toleran dari ReLU.
📐
Analogi 6
Neural Network = Kurva dari Garis-Garis Kecil
DUNIA NYATA
Kurva yang sangat kompleks (seperti huruf S, spiral, gelombang) bisa dibentuk dari banyak garis lurus kecil yang disambung dengan sudut tertentu. Makin banyak garis → makin mulus kurvanya.
DI AI
Pola data yang kompleks bisa dipelajari dari banyak persamaan linier kecil yang disambung dengan activation function. Makin banyak neuron/layer → makin kompleks pola yang bisa dipelajari.
Universal Approximation Theorem: Neural network dengan minimal 1 hidden layer + activation function non-linier bisa mengaproksimasi fungsi apapun, sekompleks apapun.
